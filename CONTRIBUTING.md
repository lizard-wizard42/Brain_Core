# Contribuindo

1. Nunca inclua `.env`, dumps, uploads, capturas com dados reais ou builds gerados.
2. Preserve o modelo local-first: integrações externas devem ser explícitas e opt-in.
3. Para mudanças no frontend, execute `npm test` e `npm run build` em `frontend/`.
4. Para backend, execute `npm test` em `backend/`.
5. Descreva risco de segurança e impacto em dados persistentes no pull request.

Leia `AGENTS.md` para regras de build e artefatos gerados.
