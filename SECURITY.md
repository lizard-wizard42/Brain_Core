# Security policy

## English summary

Please do not open a public issue for a vulnerability that could expose data, accounts, sessions, uploads or command execution.
Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**
(GitHub private vulnerability reporting). Include a minimal description to reproduce the problem.

Never send credentials, database dumps, real attachments, cookies or keys in a report.

Priority scope: authentication, uploads, the proxy, Socket.IO, environment variables, Docker and any path that enables the terminal.

## Política de segurança

Não abra issue pública para vulnerabilidades que possam expor dados, contas,
sessões, uploads ou execução de comandos. Relate de forma privada pelo GitHub:
abra a aba **Security** do repositório e escolha **Report a vulnerability**
(relato privado de vulnerabilidade do GitHub). Inclua uma descrição mínima para reprodução.

Não envie credenciais, dumps, anexos reais, cookies ou chaves em relatos.

O escopo prioritário inclui autenticação, uploads, proxy, Socket.IO, variáveis
de ambiente, Docker e qualquer caminho que habilite o terminal.
